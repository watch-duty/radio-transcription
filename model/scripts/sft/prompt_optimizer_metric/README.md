# Prompt Optimizer ASR Metric

Deploy this directory as an HTTP Cloud Run function before launching VAPO with
`metric_mode = custom`.

Example:

```bash
gcloud functions deploy wd-asr-wer-score \
  --gen2 \
  --runtime=python312 \
  --region=us-central1 \
  --source=model/scripts/sft/prompt_optimizer_metric \
  --entry-point=asr_wer_score \
  --trigger-http \
  --no-allow-unauthenticated \
  --memory=2Gi \
  --timeout=300s
```

The returned metric key is `asr_wer_score`, matching the default VAPO config
generated by `run_prompt_optimizer_gate.py`.
