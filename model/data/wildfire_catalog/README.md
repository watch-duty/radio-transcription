# Wildfire Feed Catalog Builder

This directory contains the catalog crawler used by
`backend/scripts/load_test_feeds.py seed-catalog`.

Most operators should not run these files directly. Use the runbook instead:

```bash
less backend/scripts/load_test_feeds.md
```

The crawler discovers wildfire-relevant scanner feeds from Broadcastify Feeds,
Broadcastify Calls, and OpenMHz, scores them, and writes generated catalog
files under `output/`.

Generated directories are intentionally not committed:

- `cache/`: provider API response cache
- `output/`: generated CSV/JSON catalog artifacts

The load-test script imports:

```text
model/data/wildfire_catalog/output/wildfire_feed_catalog_admin_review.csv
```

That file is generated by:

```bash
uv run python model/data/wildfire_catalog/run_catalog.py \
  --skip-echo \
  --output-dir model/data/wildfire_catalog/output
```

`seed-catalog` runs that command for you, then imports the generated Tier 1+2
Broadcastify/OpenMHz rows into AlloyDB as deactivated load-test feeds.
