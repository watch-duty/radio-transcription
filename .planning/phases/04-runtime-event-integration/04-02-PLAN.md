<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Collector code -> runtime | Collectors classify failures but do not mutate DB or write audit rows. |
| Runtime -> storage | Runtime passes actor/prior-state inputs; storage decides and persists events. |
| Runtime logs/diagnostics -> storage | Failure reasons cross into durable diagnostic detail through storage sanitization. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-02-01 | Repudiation | Runtime actor | mitigate | Use one explicit `service:collector-runtime` actor constant for all async runtime audit-capable calls. |
| T-04-02-02 | Tampering | Prior state | mitigate | Pass prior state from `LeasedFeed` returned by storage, not from collector-supplied data. |
| T-04-02-03 | Denial of Service | Event noise | mitigate | Preserve clean source-observation guard and rely on storage event gates for retry/noise suppression. |
| T-04-02-04 | Information Disclosure | Failure detail | mitigate | Runtime passes diagnostic reason only to storage; storage sanitizer owns durable redaction/capping. |
</threat_model>
