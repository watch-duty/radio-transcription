<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Cloud Storage notification -> Echo handler | Object notification selects a feed and starts processing; it does not provide actor identity. |
| Echo handler -> SyncFeedStore | Handler passes semantic service actor and prior feed state; sync storage owns audit persistence. |
| SyncFeedStore -> AlloyDB | Sync feed mutation and audit insert must commit together. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-03-01 | Repudiation | Echo actor | mitigate | Use explicit `service:echo-ingestion` for Echo-caused lifecycle audit events. |
| T-04-03-02 | Tampering | Echo prior state | mitigate | Resolve prior state from database through `SyncFeedStore.resolve_echo_feed`, not from event payload. |
| T-04-03-03 | Information Disclosure | Echo diagnostic detail | mitigate | Route diagnostic text through `feed_lifecycle.status_reason_detail_storage_value`. |
| T-04-03-04 | Denial of Service | Echo event noise | mitigate | Skip terminal feeds without mutation and suppress clean heartbeat audit events. |
| T-04-03-05 | Consistency | Sync mutation/audit | mitigate | Use one psycopg transaction for feed mutation and audit insert. |
</threat_model>
