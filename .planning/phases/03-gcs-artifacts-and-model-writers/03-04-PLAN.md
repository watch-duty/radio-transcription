<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| original audio URI -> Gemini JSONL | Source URI extension determines MIME metadata. |
| row text -> Gemini target turn | Transcript text becomes the model response target. |
| config fragment -> tuning runner | Config may be used by paid tuning workflows, but Phase 3 must not submit jobs. |

## STRIDE Threat Register

| Threat ID | Category | Severity | Component | Disposition | Mitigation Plan |
|-----------|----------|----------|-----------|-------------|-----------------|
| T-03-15 | Tampering | high | Gemini JSONL builder | mitigate/block | Use `common.sft.build_example()` and `validate_example()` for every row; raise `ModelWriterError` if validation fails. |
| T-03-16 | Information Disclosure | high | Gemini row serialization | mitigate/block | Pass only audio URI, transcript text, prompts, and verified MIME type; never copy `raw_row`, credentials, or arbitrary payload keys. |
| T-03-17 | Tampering | high | MIME inference | mitigate/block | Support `audio/flac` and `audio/mpeg`; unsupported extensions fail with row index and URI rather than emitting false metadata. |
| T-03-18 | Elevation of Privilege | high | tuning config | mitigate/block | Emit config fragments only; do not instantiate Vertex/GenAI clients, submit jobs, poll jobs, or record tuned model IDs. |
| T-03-19 | Tampering | high | immutable publication | transfer/mitigate | Plan 03-01 owns overwrite protection; this plan must not add direct uploads or alternate artifact roots. |
| T-03-20 | Tampering | high | benchmark/eval manifests | mitigate/block | Tests assert Gemini outputs contain only dataset-version model-input/config data and no benchmark/eval manifest paths. |
| T-03-21 | Tampering | high | dataset-version publisher | mitigate/block | `publisher.py` must call `ensure_dataset_version_absent()` once before uploads and must route every object through `upload_text_create_only()`; no direct `upload_from_string()` or `upload_file_to_blob()` calls in the publisher. |
| T-03-22 | Repudiation | high | artifact inventory | mitigate/block | Publisher tests assert returned inventory matches the expected uploaded URIs for canonical, per-dataset, model, metadata, config, and report artifacts. |
</threat_model>
