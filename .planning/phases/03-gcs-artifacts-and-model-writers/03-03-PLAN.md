<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| split rows -> model inputs | Validated `LabeledSegment` values become model-consumed JSONL. |
| writer warnings -> reports | Performance risks become dataset-version report data. |

## STRIDE Threat Register

| Threat ID | Category | Severity | Component | Disposition | Mitigation Plan |
|-----------|----------|----------|-----------|-------------|-----------------|
| T-03-10 | Tampering | high | NeMo/Whisper builders | mitigate/block | Call `validate_split_integrity()` before building rows; fail missing split or leakage. |
| T-03-11 | Information Disclosure | high | model-input rows | mitigate/block | Enumerate writer fields; do not copy `raw_row`, credentials, env paths, or arbitrary source payload keys. |
| T-03-12 | Tampering | high | model-input targets | mitigate/block | Writers return JSONL/config data for dataset-version artifact URIs only; tests reject existing benchmark/eval paths. |
| T-03-13 | Repudiation | medium | Whisper warnings | mitigate | Return structured warnings with writer, code, severity, row index, and details for D-18 reports. |
| T-03-14 | Tampering | high | immutable publication | transfer/mitigate | Plan 03-01 owns overwrite protection; this plan must not add direct GCS uploads. |
</threat_model>
