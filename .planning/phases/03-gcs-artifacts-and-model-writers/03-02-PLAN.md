<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| split output -> canonical manifests | `LabeledSegment` values become immutable JSONL rows. |
| normalized source rows -> reports | Source metadata becomes human/machine report data. |

## STRIDE Threat Register

| Threat ID | Category | Severity | Component | Disposition | Mitigation Plan |
|-----------|----------|----------|-----------|-------------|-----------------|
| T-03-05 | Tampering | high | canonical/per-dataset builders | mitigate/block | Call `validate_split_integrity()` before serializing rows; fail malformed split rows instead of emitting corrupted artifacts. |
| T-03-06 | Information Disclosure | high | canonical rows | mitigate/block | Per D-08, enumerate allowed fields and never copy `raw_row`, `.env`, or credential keys. |
| T-03-07 | Tampering | high | report builders | mitigate/block | Consume artifact inventory rooted by Plan 03-01 and do not write to benchmark/eval manifest paths. |
| T-03-08 | Repudiation | high | dataset-version reports | mitigate/block | Include resolved config, split counts/durations, leakage status, balance report, writer warnings, and artifact inventory per D-18. |
| T-03-09 | Information Disclosure | high | reports | mitigate/block | Exclude tuned model IDs, endpoints, training metrics, post-run WER, and run comparisons per D-03/D-19. |
</threat_model>
