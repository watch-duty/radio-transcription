## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| local generator -> GCS | Generated artifact text crosses into immutable cloud storage. |
| user config -> layout planner | User-controlled `dataset_version_id` determines object prefixes. |

## STRIDE Threat Register

| Threat ID | Category | Severity | Component | Disposition | Mitigation Plan |
|-----------|----------|----------|-----------|-------------|-----------------|
| T-03-01 | Tampering | high | prefix guard and uploader | mitigate/block | Per D-04/D-05, fail if `list_blobs(prefix=root_prefix, max_results=1)` returns any object and upload with `if_generation_match=0`; convert 412/precondition failure to `DatasetVersionExistsError`. |
| T-03-02 | Information Disclosure | high | artifact inventory | mitigate/block | Tests assert inventory contains no `raw_row`, `.env`, credential variable names, or local secret paths. |
| T-03-03 | Tampering | high | malformed rows | mitigate/block | This plan exposes only layout/upload primitives; row validation is required in plans 03-02 through 03-04 before publication. |
| T-03-04 | Tampering | high | benchmark/eval manifests | mitigate/block | Layout roots generated URIs under `gs://wd-transcription-data/sft/{dataset_version_id}/`; tests reject `model/data`, `benchmark`, and `inference_manifests` targets. |
</threat_model>
