<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Enriched segment -> JSON report | Transformation metadata becomes audit output. |
| Enriched segment -> Markdown report | Human-readable report summarizes actions and provenance completeness. |

## STRIDE Threat Register

| Threat ID | Category | Severity | Component | Disposition | Mitigation Plan |
|-----------|----------|----------|-----------|-------------|-----------------|
| T-04-01 | Tampering/Elevation | high | subprocess helpers | transfer/mitigate | Plan 04-01 owns subprocess execution; reports summarize command/version metadata only and must not execute commands. |
| T-04-02 | Tampering | high | generated GCS object names | transfer/mitigate | Plan 04-01 owns object naming; reports count model-ready/derived URIs without generating paths. |
| T-04-03 | Tampering | high | GCS overwrite/race | transfer/mitigate | Plan 04-02 owns publication writes; reports are pure in-memory builders. |
| T-04-04 | Denial of Service | high | external URL downloads | transfer/mitigate | Plan 04-01 owns bounded downloads; reports do not download or probe audio. |
| T-04-05 | Information Disclosure | high | model-ready audio leakage | mitigate/block | Report builder fails if model-ready audio is missing or not `gs://`; report summarizes provenance without raw subprocess output or raw source payloads. |
| T-04-06 | Repudiation | medium | audit report | mitigate | JSON and Markdown reports include action counts, metadata key coverage, and command summary counts for every generated dataset version. |
</threat_model>
