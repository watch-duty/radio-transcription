<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Enriched segment -> model writers | Model inputs are generated from prepared audio fields. |
| Audio preparation -> final manifests | Binary audio uploads occur before canonical/model/report text artifacts. |
| Dataset-version root -> GCS writes | All generated artifacts share one immutable GCS prefix. |

## STRIDE Threat Register

| Threat ID | Category | Severity | Component | Disposition | Mitigation Plan |
|-----------|----------|----------|-----------|-------------|-----------------|
| T-04-01 | Tampering/Elevation | high | subprocess helpers | transfer/mitigate | Plan 04-01 owns argv-only ffprobe/ffmpeg helpers; this plan must consume `prepare_audio_for_publication()` and must not add subprocess execution to `publisher.py` or `model_writers.py`. |
| T-04-02 | Tampering | high | generated audio object names | transfer/mitigate | Plan 04-01 owns safe action-based names; publisher must use audio results and inventory only, not construct raw audio paths. |
| T-04-03 | Tampering | high | GCS overwrite/race | mitigate/block | Publisher calls `ensure_dataset_version_absent()` once before uploads and text writes continue through `upload_text_create_only()`; audio writes are delegated to Plan 04-01 `upload_file_create_only()`. |
| T-04-04 | Denial of Service | high | external URL downloads | transfer/mitigate | Publisher delegates all download/staging to Plan 04-01; tests use fake `audio_preparer` and do not add network access. |
| T-04-05 | Information Disclosure | high | model-ready audio leakage | mitigate/block | Writers require non-empty `gs://` `model_ready_audio_uri`; publisher feeds only enriched segments into writers so external source URLs cannot become model-ready outputs. |
| T-04-06 | Repudiation | medium | publication order | mitigate | Publisher tests assert audio preparation happens before final text artifacts and prefix absence is checked once before all uploads. |
</threat_model>
