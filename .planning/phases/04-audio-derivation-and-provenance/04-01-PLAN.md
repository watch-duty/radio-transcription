<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Manifest row -> subprocess argv | User-controlled source URIs and offsets become ffprobe/ffmpeg arguments. |
| External URL -> local scratch file | Non-GCS source audio is downloaded before probing and publication. |
| Row identity -> GCS object path | Dataset/source fields influence generated audio object names. |
| Local file -> GCS object | Copied, derived, and transcoded binary files are uploaded to dataset-version storage. |
| Audio transformation -> model-ready manifest fields | Derived output becomes the audio consumed by model writers. |

## STRIDE Threat Register

| Threat ID | Category | Severity | Component | Disposition | Mitigation Plan |
|-----------|----------|----------|-----------|-------------|-----------------|
| T-04-01 | Tampering/Elevation | high | `probe_audio()`, `derive_audio_clip()`, `transcode_audio_file()` | mitigate/block | Use `subprocess.run()` argv lists only, never `shell=True`; tests assert command shape and absence of shell invocation. |
| T-04-02 | Tampering | high | `audio_object_uri()` | mitigate/block | Generate object names from safe row identity plus a short hash; reject unsafe path parts; never embed raw source URI, raw source_group, or split in audio paths. |
| T-04-03 | Tampering | high | `upload_file_create_only()` | mitigate/block | Use `upload_from_filename(..., if_generation_match=0)` and map precondition failures to `DatasetVersionExistsError`. |
| T-04-04 | Denial of Service | high | `stage_source_audio()` | mitigate/block | Allow only `gs://`, `http://`, and `https://`; external downloads use timeouts, streamed chunks, and `EXTERNAL_DOWNLOAD_MAX_BYTES = 512 * 1024 * 1024`. |
| T-04-05 | Information Disclosure | high | `prepare_audio_for_publication()` | mitigate/block | Populate `model_ready_audio_uri` only with `gs://`; fail if any action cannot produce a model-ready GCS URI; preserve source URI only in provenance fields. |
| T-04-06 | Repudiation | medium | transformation metadata | mitigate | Record action, source/output probe fields, split, source_group, and command/version summaries for every enriched row. |
</threat_model>
