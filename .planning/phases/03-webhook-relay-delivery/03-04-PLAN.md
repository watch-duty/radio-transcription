<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Pub/Sub -> Cloud Run relay | Route module grants a dedicated push invoker access to the relay. |
| Secret Manager -> relay env | WD API key is injected into the relay container without plaintext Terraform logs. |
| Terraform/app-deploy -> Cloud Run image | Deployment workflow builds and deploys the public relay Dockerfile. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-04-S01 | Spoofing | Pub/Sub push invoker | mitigate | Keep route module OIDC push config and Cloud Run `roles/run.invoker` binding to the dedicated push invoker service account. |
| T-03-04-I01 | Information Disclosure | WD API key | mitigate | Store API key in Secret Manager, expose via `value_source.secret_key_ref`, and mark Terraform input sensitive. |
| T-03-04-D01 | Denial of Service | Pub/Sub ack deadline | mitigate | Set `ack_deadline_seconds = 60` so Pub/Sub does not timeout the request before the relay finishes its two local WD attempts. |
| T-03-04-E01 | Elevation of Privilege | Relay runtime service account | mitigate | Grant only secret accessor plus log/monitor/trace roles; explicitly avoid DB, Redis, storage, and Pub/Sub data-plane roles. |
</threat_model>
