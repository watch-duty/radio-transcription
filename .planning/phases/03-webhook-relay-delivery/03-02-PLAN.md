<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Pub/Sub HTTP request -> parser | External JSON envelope enters service code. |
| Cloud Logging LogEntry -> WD payload | Decoded log data becomes outbound WD request payload. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-02-S01 | Spoofing | Parser input | mitigate | Accept only the Pub/Sub push envelope shape expected from the authenticated subscription; do not accept raw payload fallback. |
| T-03-02-T01 | Tampering | `jsonPayload` contract | mitigate | Validate event type, schema version, and required v1 keys before forwarding. |
| T-03-02-I01 | Information Disclosure | Validation errors | mitigate | Return generic invalid-message errors and avoid logging full payloads beyond event identifiers. |
| T-03-02-D01 | Denial of Service | Malformed messages | mitigate | Raise a bounded parser exception and return non-2xx so Pub/Sub retry/DLQ owns repeated failures. |
</threat_model>
