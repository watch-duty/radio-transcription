<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Relay -> WD backend | Relay sends authenticated HTTP requests outside the transcription service boundary. |
| Pub/Sub retry -> relay local retry | Inner local retry and outer Pub/Sub retry interact and must not hide failure. |
| Runtime logs -> operators | Logs expose debugging context but must not expose credentials. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-03-S01 | Spoofing | WD outbound auth | mitigate | Send only `X-Api-Key` from Secret Manager-backed env; never accept API key from inbound payload. |
| T-03-03-I01 | Information Disclosure | Relay logs | mitigate | Tests assert API key is absent from failure and success logs. |
| T-03-03-D01 | Denial of Service | Retry loop | mitigate | Exactly two local attempts with small jitter; Pub/Sub owns outer retry and DLQ. |
| T-03-03-R01 | Repudiation | ACK semantics | mitigate | Return `204` only after WD `2xx`; all failures return non-2xx so Pub/Sub retry/DLQ preserves evidence. |
</threat_model>
