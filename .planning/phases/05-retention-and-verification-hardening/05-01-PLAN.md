    The file must define this concrete procedure shape:

    ```sql
    CREATE OR REPLACE PROCEDURE public.prune_feed_audit_events_retention()
    LANGUAGE plpgsql
    AS $$
    BEGIN
        WITH expired_events AS MATERIALIZED (
            SELECT id
            FROM public.feed_audit_events
            WHERE occurred_at < NOW() - INTERVAL '18 months'
            ORDER BY occurred_at, id
            LIMIT 10000
            FOR UPDATE SKIP LOCKED
        )
        DELETE FROM public.feed_audit_events events
        USING expired_events
        WHERE events.id = expired_events.id;

        WITH orphaned_sequences AS MATERIALIZED (
            SELECT sequences.feed_id
            FROM public.feed_audit_event_sequences sequences
            WHERE NOT EXISTS (
                SELECT 1
                FROM public.feeds feeds
                WHERE feeds.id = sequences.feed_id
            )
              AND NOT EXISTS (
                SELECT 1
                FROM public.feed_audit_events events
                WHERE events.feed_id = sequences.feed_id
            )
            ORDER BY sequences.feed_id
            LIMIT 10000
            FOR UPDATE SKIP LOCKED
        )
        DELETE FROM public.feed_audit_event_sequences sequences
        USING orphaned_sequences
        WHERE sequences.feed_id = orphaned_sequences.feed_id;
    END;
    $$;
    ```

    Preserve these exact values: `occurred_at < NOW() - INTERVAL '18 months'`, `LIMIT 10000`, `FOR UPDATE SKIP LOCKED`, `DELETE FROM public.feed_audit_events`, `DELETE FROM public.feed_audit_event_sequences`, and the two `NOT EXISTS` predicates against `public.feeds` and `public.feed_audit_events`. Do not add `INSERT INTO feed_audit_events`, `UPDATE public.feed_audit_events SET feed_sequence`, `created_at <`, loops, archive tables, tombstone events, or sequence renumbering.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| AlloyDB scheduler -> audit tables | DB-owned scheduled SQL deletes audit rows and sequence bookkeeping. |
| Migration files -> local/CI schema helpers | `*pg_cron*` migrations are skipped outside AlloyDB; executable retention SQL must remain in the extension-free migration. |
| Retention SQL -> audit evidence | Retention may remove historical evidence only under the approved 18-month policy. |
| Documentation/tests -> future implementers | Contract text and static tests prevent later code from changing retention into archival, redaction, renumbering, or app-owned deletion. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-01-01 | Tampering | `031_feed_audit_event_retention.sql` | mitigate | Delete only rows selected by `occurred_at < NOW() - INTERVAL '18 months'` in a bounded `LIMIT 10000` CTE with `FOR UPDATE SKIP LOCKED`; static tests reject `created_at <`, synthetic inserts, archives, tombstones, and sequence renumbering. |
| T-05-01-02 | Repudiation | `feed_audit_events` retention | mitigate | Preserve immutable surviving `feed_sequence` values and document expected gaps so retained timelines do not imply first-ever event ordering after expiry. |
| T-05-01-03 | Denial of Service | Daily retention cleanup | mitigate | Run one bounded batch per daily job and do not loop inside the procedure; static tests require `LIMIT 10000`. |
| T-05-01-04 | Information Disclosure | Diagnostic/audit payload retention | mitigate | Retention deletes expired rows only and does not rewrite or redact retained payloads; existing diagnostic sanitizer tests remain the control for secrets in retained rows. |
| T-05-01-05 | Elevation of Privilege | Public/service retention control | mitigate | Add no public API, service method, runtime path, or frontend path for retention; scheduling remains inside AlloyDB pg_cron. |
| T-05-01-06 | Tampering | `feed_audit_event_sequences` cleanup | mitigate | Prune sequence rows only when no `feeds` row exists and no retained `feed_audit_events` rows exist, preserving sequence state for live feeds and deleted feeds with retained history. |
</threat_model>
