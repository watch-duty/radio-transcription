<threat_model>
Trust boundaries:
- Vertex batch output is durable GCS state from a previous paid run.
- The output prefix can contain JSONL files even when prompt, manifest, context,
  or target model changed.
- Batch submission is paid work and should not happen as a hidden recovery from
  stale artifacts.

STRIDE register:
- DUR-T4 stale-output tampering: path-based output reuse can score predictions
  from a different request. Mitigation: require matching
  `batch_predictions.meta.json` before reuse.
- DUR-T5 cost surprise: metadata mismatch could trigger an implicit new batch
  job. Mitigation: if output exists but metadata is missing or mismatched, raise
  before calling `submit_fn`.
- DUR-T6 replay ambiguity: batch output prefixes are not append-safe like the
  online JSONL path. Mitigation: batch reuse requires exact audio URI identity,
  not smoke-prefix reuse.
</threat_model>
