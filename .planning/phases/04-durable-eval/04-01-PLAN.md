<threat_model>
Trust boundaries:
- Local TOML is operator input and can contain old plural tables that no longer
  match the run contract.
- Durable GCS `config.json` is the eval source of truth and can contain stale
  plural state from older runs.
- Target labels become GCS artifact path segments.

STRIDE register:
- DUR-T1 spoofed target set: plural `[[eval.models]]` can make operators think
  multiple targets are evaluated in one run. Mitigation: reject `eval.models`
  and require exactly one `[eval.model]`.
- DUR-T2 stale durable config: old `eval_models` in GCS can silently drive the
  old loop. Mitigation: `require_config_eval_model` fails if `eval_models` is
  present and requires exactly `eval_model.label` plus `eval_model.model`.
- DUR-T3 artifact path tampering: unsafe labels can escape artifact prefixes.
  Mitigation: continue validating the singular label with
  `validate_artifact_label`.
</threat_model>
