<threat_model>
Trust boundaries:
- The validation CLI reads a user-supplied config URI and configured GCS
  manifests/source maps.
- CLI/log output is visible to operators and should be useful without leaking
  full raw rows.

STRIDE register:
- T-01-07 Tampering: a bad manifest could pass with zero usable examples.
  Mitigation: zero valid examples after exclusions is a hard validation error.
- T-01-08 Repudiation: short errors might omit enough context to debug.
  Mitigation: validation errors include dataset name, manifest URI, strategy,
  row index when available, reason, and relevant source/audio fields.
- T-01-09 Information disclosure: CLI summaries could dump raw rows.
  Mitigation: summary prints counts and contextual failure fields only.
</threat_model>
