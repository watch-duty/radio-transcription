<threat_model>
Trust boundaries:
- Vertex batch output is external provider data and may omit rows.
- GCS URIs are provenance data shown to operators.
- Local `results/` files are cache/mirror artifacts, not authoritative state.

STRIDE register:
- RPT-T4 repudiation: Operators cannot later tell which raw batch output
  produced a reported metric. Mitigation: every target row includes
  `raw_output_uri` and `normalized_manifest_uri`.
- RPT-T5 tampering by omission: Missing provider rows can disappear from WER
  if the implementation filters them. Mitigation: tests assert
  `missing_prediction_count` and WER denominator behavior when one eval row has
  no prediction.
- RPT-T6 denial of clarity: Console, JSON, and Markdown can disagree if batch
  eval keeps bespoke rendering. Mitigation: `records.write_wer_summary` writes
  shared report dictionary and Markdown generated by `gemini_sft.reporting`.
</threat_model>
