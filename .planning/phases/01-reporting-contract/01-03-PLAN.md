<threat_model>
Trust boundaries:
- Checkpoint endpoint responses arrive through online `generate_content` and
  can be empty, absent, retried, or partially cached.
- Online prediction JSONL in GCS is resumable state and provenance.
- Console output may be used directly for checkpoint selection.

STRIDE register:
- RPT-T7 tampering by stale partial predictions: A resumed checkpoint run can
  reuse local/GCS rows. Mitigation: keep existing resumable prediction logic
  unchanged and report the `online_predictions_uri` used for each checkpoint.
- RPT-T8 spoofing by best-only output: A single best-checkpoint JSON can hide
  worse rows and omit full metric context. Mitigation: print the full shared
  report table before any best-checkpoint convenience output.
- RPT-T9 ambiguity in empty metrics: Legacy `empty_rate`/`hallucination_rate`
  names can be misread. Mitigation: checkpoint report rows expose only
  canonical public names.
</threat_model>
