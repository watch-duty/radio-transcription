<threat_model>
Trust boundaries:
- Provider/model output enters the reporting layer as untrusted text.
- GCS artifact URIs are operator-facing provenance links and must stay attached
  to the correct target row.
- Console/Markdown output may be copied into tickets or promotion discussions.

STRIDE register:
- RPT-T1 spoofing/mix-up: A report row can show metrics for one target and
  artifact URIs for another target. Mitigation: `TargetMetrics` owns both
  metrics and `ReportArtifacts`; tests assert artifacts remain in the same row.
- RPT-T2 tampering by drift: Console, Markdown, and JSON can diverge if each
  has separate column definitions. Mitigation: define one `REPORT_COLUMNS`
  sequence in `gemini_sft.reporting` and render every format from it.
- RPT-T3 information disclosure: Raw transcript text should not appear in the
  summary report. Mitigation: report schema contains aggregate metrics and URIs
  only, not per-row reference or hypothesis text.
</threat_model>
