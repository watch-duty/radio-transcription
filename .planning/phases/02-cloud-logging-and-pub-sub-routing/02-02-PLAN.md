<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Cloud Logging -> Pub/Sub topic | The sink writer identity crosses into Pub/Sub publishing. |
| Pub/Sub -> Cloud Run relay | Pub/Sub pushes HTTP requests to a private Cloud Run service endpoint. |
| Pub/Sub service agent -> service account / DLQ | The managed Pub/Sub service agent signs OIDC tokens and handles dead-letter movement. |
| Route module -> Phase 3 relay | The route consumes relay URL/name inputs but does not create relay runtime resources. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-02-E01 | Elevation of Privilege | `google_pubsub_topic_iam_member.sink_publisher` | mitigate | Grant `roles/pubsub.publisher` only on `var.notification_topic_name` to `google_logging_project_sink.feed_audit_notification.writer_identity`; no project-level publisher grant. |
| T-02-02-E02 | Elevation of Privilege | Terraform deployer ActAs | mitigate | Grant `roles/iam.serviceAccountUser` only on `google_service_account.push_invoker.name` to `var.deployer_service_account_email`, because Pub/Sub authenticated push subscription creation requires ActAs on the OIDC service account. |
| T-02-02-S01 | Spoofing | Pub/Sub push invocation | mitigate | Use dedicated `google_service_account.push_invoker`, set it in `push_config.oidc_token.service_account_email`, and grant only that account `roles/run.invoker` on `var.relay_service_name`. |
| T-02-02-S02 | Spoofing / Denial of Service | Path-based OIDC audience | mitigate | Set `push_endpoint = "${var.relay_service_url}/pubsub/feed-audit-notifications"` and `oidc_token.audience = var.relay_service_url` to avoid defaulting the audience to the path URL. |
| T-02-02-D01 | Denial of Service / Availability | Pub/Sub retry and DLQ | mitigate | Configure `minimum_backoff = "10s"`, `maximum_backoff = "60s"`, `max_delivery_attempts = 10`, DLQ publisher IAM, and source subscription subscriber IAM for the Pub/Sub service agent. |
| T-02-02-T01 | Tampering | Sink filter | mitigate | Use only the locked event contract filter and do not add mutable service/resource/environment emitter filters that could drop valid future producers. |
</threat_model>
