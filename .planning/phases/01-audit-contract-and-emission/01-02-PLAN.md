<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| database driver -> helper | Driver-returned JSONB may arrive as mapping or string and must be normalized safely. |
| helper -> logging subsystem | Local logging can fail and must not affect storage callers. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-02-S01 | Spoofing | `emit_feed_audit_notification` | mitigate | Helper accepts a single `feed_audit_event` object and no request-local fields; it shallow-validates exact `event_type` and `schema_version` before logging. |
| T-01-02-I01 | Information Disclosure | `feed_audit_notifications.py` | mitigate | Helper emits only the database-returned flat payload and does not add request bodies, secrets, delivery metadata, or webhook-only fields. |
| T-01-02-D01 | Denial of Service | `emit_feed_audit_notification` | mitigate | Wrap normalization and `logger.info` in `try/except Exception` and never re-raise local logging failures per AUDIT-03/D-11. |
| T-01-02-E01 | Elevation of Privilege | storage helper imports | mitigate | Do not import Pub/Sub, webhook clients, Cloud Logging client APIs, network clients, or deployment config into the storage helper per D-12. |
</threat_model>
