<threat_model>
Trust boundaries:
- Manifest rows are user-controlled and can contain skewed, duplicated, or
  malformed source distributions.
- The optimizer dependency is external package code.

STRIDE register:
- T-02-01 Tampering: row-level assignment could split one Source Group across
  train and eval. Mitigation: split.py assigns at Source Group granularity and
  writes one split value for all rows in a group.
- T-02-02 Denial of service: a large Source Group set could make solving slow.
  Mitigation: use a bounded CP-SAT solve time and accept FEASIBLE or OPTIMAL
  status with metadata.
- T-02-03 Repudiation: non-deterministic solving could make a split hard to
  audit. Mitigation: report algorithm name, OR-Tools status, objective value,
  weights, solver time limit, and the chosen Source Group assignment.
</threat_model>
