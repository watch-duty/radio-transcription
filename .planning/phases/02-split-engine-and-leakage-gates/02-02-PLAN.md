Trust boundaries:
- Split results may be produced from user-controlled manifests or future
  model-writer rows.
- Audio URIs can be repeated accidentally across configured datasets.

STRIDE register:
- T-02-04 Tampering: a bad Source Group or duplicated input file could put
  the same upstream audio in train and eval. Mitigation: exact cross-split
  set intersections fail the run.
- T-02-05 Repudiation: duplicate rows within one split could make training
  statistics unclear. Mitigation: exact duplicate audio spans fail with a
  short field-specific error.
- T-02-06 Information disclosure: errors should not dump full raw rows.
  Mitigation: errors include only field name and conflicting key.
</threat_model>
