<threat_model>
Trust boundaries:
- Local TOML is operator input and can contain unsupported execution fields or
  unsafe values that would otherwise affect paid Vertex work.
- Backend routing decides whether a target uses batch jobs or online
  generate-content calls.
- Smoke limits change the evaluated denominator and must be explicit.

STRIDE register:
- EXEC-T1 tampering by config overgrowth: unsupported execution keys can become
  accidental API. Mitigation: `[eval.execution]` rejects every key except
  `backend`, `limit`, `concurrency`, and `max_retries`.
- EXEC-T2 spoofing backend intent: an `auto` value would look explicit while
  meaning default routing. Mitigation: accept only `batch` or `online`; omitted
  backend is the only default route.
- EXEC-T3 cost ambiguity: endpoint resources can be sent to the wrong backend
  before validation. Mitigation: deterministic offline resolver routes full
  endpoint resources to online unless the config-wide backend forces batch.
</threat_model>
