<threat_model>
Trust boundaries:
- Existing online prediction JSONL is durable state from previous runs and may
  have been produced by a different prompt, model, eval manifest, or limit.
- Online endpoint calls are paid work and can fail per row.
- Local `results/` files are only mirrors; GCS prediction and metadata
  artifacts are the authoritative resume inputs.

STRIDE register:
- EXEC-T4 stale-output tampering: A mismatched prediction JSONL can be reused
  after prompt or manifest changes. Mitigation: require matching
  `online_predictions.meta.json` request identity before skipping rows.
- EXEC-T5 denial of progress: One row can exhaust retries and abort the whole
  target. Mitigation: persist an empty prediction row with an `error` value and
  continue processing remaining rows.
- EXEC-T6 replay confusion: A smoke-limited result can be mistaken for a full
  eval. Mitigation: request identity stores evaluated audio URI order and only
  allows prefix reuse when the prior URI list is an exact prefix.
</threat_model>
