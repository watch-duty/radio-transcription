<threat_model>
Trust boundaries:
- GCS `config.json` is authoritative and can differ from the local TOML.
- Eval manifest rows define the scoring denominator and prior-context order.
- Batch and online provider outputs can be partial or missing.

STRIDE register:
- EXEC-T7 stale target fallback: The old runner can silently execute
  `base_model`/`endpoint` instead of durable `eval_models`. Mitigation:
  remove the supported-target comparison and iterate only
  `require_config_eval_models(config)`.
- EXEC-T8 denominator tampering: Applying `limit` to only eval rows or only
  source rows can corrupt histories. Mitigation: apply the limit immediately
  after canonical parsing to both source rows and eval rows before histories
  and audio URI lists are built.
- EXEC-T9 repudiation of online failures: Failed rows can be hidden as missing
  rows. Mitigation: include online `error_count` in target metadata and keep
  every failed row as `pred_text = ""`.
</threat_model>
