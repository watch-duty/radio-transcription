<threat_model>
Trust boundaries:
- Placeholder docs can be copied into real paid run configs.
- Masked and unmasked eval artifacts share the same bucket hierarchy and can
  mix if `round_id` or `inference_dataset_slug` is ambiguous.
- Extra fields in examples tend to become de facto API even when backend
  routing is deferred.

STRIDE register:
- CFG-T7 tampering by ambiguous examples: If examples imply `type`, `backend`,
  or `eval_label`, operators may create configs Phase 2 rejects. Mitigation:
  examples show only `label` and `model`, and explain masked/unmasked as
  separate configs.
- CFG-T8 artifact collision: Masked and unmasked runs can write into the same
  prefix. Mitigation: docs and tests require distinct `round_id` values and
  explicit `inference_dataset_slug`.
- CFG-T9 overvalidation drift: Docs can imply semantic checks for words like
  `masked`. Mitigation: tests assert slug syntax is validated while no
  `masked = true` field or semantic masked-word enforcement exists.
</threat_model>
